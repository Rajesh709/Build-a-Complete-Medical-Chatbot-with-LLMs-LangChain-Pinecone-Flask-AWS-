
# 🩺 Build-a-Complete-Medical-Chatbot-with-LLMs-LangChain-Pinecone-Flask-AWS

An AI-powered chatbot that can answer medical questions by processing uploaded PDF documents. Built using:

- 🧠 **LangChain** for managing LLM prompts and logic
- 🌲 **Pinecone** as a vector database for document retrieval
- 🔥 **Flask** for backend API development
- ☁️ **AWS** for optional deployment

## 🚀 Features

- 📄 Upload medical PDFs and ask questions about them
- 🔍 Semantic search powered by Sentence Transformers
- 🧠 Context-aware answers using OpenAI's LLMs (GPT-3.5/GPT-4)
- 🔗 Modular and extendable codebase
- 🌐 API-based structure for front-end or chat UI integration
